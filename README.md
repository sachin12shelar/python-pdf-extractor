
# PDF Table Extractor

A Python-based desktop application that extracts structured tables from PDF documents and exports the extracted data into CSV and Excel formats.

## Features

- Open and process PDF documents.
- Automatically identify relevant tables using header keywords.
- Manually select tables from PDF pages.
- Extract tables with merged cells and multi-row headers.
- Preview extracted data in a table format.
- Rename or remove columns before exporting.
- Export extracted data to CSV.
- Automatically process multiple PDF files from a folder.

## Technologies Used

- Python
- Tkinter
- PyMuPDF
- pdfplumber
- Pandas

## How It Works

1. Open a PDF document.
2. Identify the required table using automatic or manual selection.
3. Provide relevant header keywords to identify the table.
4. Preview the extracted data.
5. Rename or remove columns if required.
6. Export the verified data into CSV.
7. Process multiple PDF files using folder automation.

## Use Cases

- Product specification sheets
- Lighting performance tables
- Technical datasheets
- Product catalogues containing structured tables
